# Scoped manual learning reviews

FG-00-Q2A extends IRuntimeStore, not the API or a second learning authority. LearningService.ReviewAsync delegates to a default port which uses its existing cohesive callback. PostgreSQL overrides that port with async keyed reads and writes on RuntimeLearningRows. Both paths use LearningService.DecideReview and the existing TrainingProjection.Manual. Atomic voice/session transitions retain LearningService.Apply.

The scoped writer takes the existing privacy SHARE gate, then the same RuntimeDocuments singleton FOR UPDATE lock as general runtime/session writers. Time is sampled after acquiring that writer lock. The request receipt is read first and validates the same card/rating/response-time/timing-source fingerprint; identical replay returns its original stored result even after card deletion or later correction. New reviews read the target card and baseline, validate canonical identities, and allocate the existing sequence if a baseline exists. Card JSON/index timestamp, immutable receipt and optional sequence/control update commit together. Overflow, cancellation or duplicate sequence failure rolls back the whole transaction. There is no new sequence namespace, schema or migration. The root document is locked without loading its payload or changing its fingerprint.

Scope is the existing HTTP/manual review command. Assessment corrections, voice composite transactions, general writes and history reads retain their full transactional behavior. Existing privacy export/erasure see the same canonical rows; stale requests cannot reach receipts after erasure. Other histories, baselines, membership sets, audio and cold payloads are not hydrated by the scoped writer. No provider, client, security or Forge activation change.

Acceptance combines async keyed-query interception, rollback/replay/restart/concurrency/privacy tests and existing training/voice regressions. An opt-in synthetic benchmark compares the old callback and new port for the same review workload on identically seeded databases. It does not re-label the earlier generic stability-edit measurement or claim a universal latency guarantee under lock contention.
